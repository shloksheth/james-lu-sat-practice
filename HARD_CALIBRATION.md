# Hard-question calibration

The full College Board export was indexed before updating the practice library. It contains 1,785 unique PSAT/NMSQT and PSAT 10 math questions, including 755 labeled **Hard**. The hard set is concentrated in multi-step applications, parameter constraints, systems, nonlinear functions, equivalent expressions, inequalities, models and scatterplots, geometry, and trigonometry.

The course practice now carries a hard-calibration label for every lesson. The label identifies the reasoning pattern being emphasized; the practice remains independently authored and does not reproduce College Board questions.

Before publishing the hard calibration, the generated math answer key was checked for arithmetic and explanation consistency. Two errors were corrected:

- Single Variable Equations, question 3: `(3x + 1)/(x − 2) = 4` has answer `9`, not `11`.
- Regression Part 1, question 4: the model values `7, 11, 19` give `c = 5`, not `3`.

The official hard-question labels were used as a difficulty reference, not as copied content.
